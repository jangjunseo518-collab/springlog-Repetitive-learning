# 반복 학습

## 반복 학습 방법
- develop이나 main에 따로 병합하지 않고 stage 별로 브랜치를 나눠 반복 학습을 이어간다.
- 새로운 반복되는 패턴을 실습하는 브랜치를 develop에서 만든다. (develop은 항상 환경 설정만 끝난 상태로 유지한다.)
- 이 저장소에서는 stage 별로 반복되는 패턴을 연습하며 구조를 익힌다.
- 원본 코드를 보지 않고 해당 구조를 구현할 수 있게 되는 것이 목표이다.
- stage ${n}$ / ${n}$ try의 형태로 브랜치를 만든다 EX) stage1/1try
- 반복 학습을 이어가며 브랜치를 커밋할 때 stage${n}$_${n}$try회고록.md 회고를 남긴다.
# stage1_1try회고록.md

* enum, BaseEntity는 안 보고 완성
* 정규화 로직에서 category 파라미터 빼먹음 (2회차에도 반복될 수 있음 -> 요주의)
* protected 생성자 이유 다시 헷갈림
