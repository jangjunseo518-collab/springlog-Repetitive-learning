# 반복 학습

## 반복 학습 방법
- base 브랜치는 항상 초기 상태를 유지한다.
- 최초 시작은 base브랜치에서 시작한다.
- stage 별로 브랜치를 나눠 반복 학습을 이어간다.
- 원본 코드를 보지 않고 해당 구조를 구현할 수 있게 되는 것이 목표이다.
- stage${n}$/${n}$try의 형태로 브랜치를 만든다 EX) stage1/1try
- 반복 학습을 이어가며 완료 후 push할 때 회고록.md파일에 이름을 stage${n}$_${n}$try 회고록으로 변경하고 회고를 남긴다.
- 화고록.md는 회고록 패키지 안에 있다.
- 통과한 브랜치는 develop에 병합한다.
-  [심화 1]: 이전 학습과 병행 연습
   stage 2 부터는 완료 후 이전 단계를 포함해서 빌드하도록 연습한다.  
   통합 빌드는 integration 브랜치를 이용하자.
   ex) stage2완료 후 stage1~stage2를 한번에 빌드/ stage3완료 후 stage2~stage3 까지 빌드  
   -> 이전 단계부터 현제 단계까지 빌드하자 (추후 도메인이 추가되면 도메인 단위로 해도 무관.)
- [심화 2]: 응용 학습
  스테이지가 3회 이상 반복되며 채득되면 설계 감을 익혔는지 단순 코드 자체를 외운 건지 구분이 어려워 질 것이다.  
  그래서 심화 1을 완료한다면 현제 스테이지에서 도메인에 원본 프로젝트에 없는 다른 요구사항 하나를 추가하여 구현해보자.
  도서 대여, 예약, 게시판, 등등 뭐든 좋다. 단, 너무 큰 작업 말고 작은 요구사항을 추가하도록하자.  
  심화 2는 따로 프로젝트를 만들어서 다른 서비스를 구현하자.(나는 운동 루틴을 관리하는 프로잭트로 함)
